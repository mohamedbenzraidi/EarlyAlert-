PROJECT: EarlyAlert — Système de prédiction de détérioration en réanimation

OBJECTIF: Prédire les détériorations critiques 4-6 heures avant qu'elles ne soient
          cliniquement visibles, à partir de constantes vitales et biomarqueurs.

STACK:
  ✅ Python 3.10
  ✅ TensorFlow 2.13 / Keras
  ✅ Pandas, NumPy, Scikit-learn
  ✅ Streamlit (Dashboard)
  ✅ MIMIC-IV (300k+ séjours réels)

ARCHITECTURE MODÈLE:
  Input (24 timesteps × 13 features)
    ↓
  BiLSTM(64) + LayerNorm + Dropout(0.3)
    ↓
  BiLSTM(32) + Dropout(0.3)
    ↓
  Attention Bahdanau (identification moments critiques)
    ↓
  Dense(64, relu) + Dropout(0.3)
    ↓
  Dense(32, relu)
    ↓
  Dense(1, sigmoid) → Probabilité [0.0 à 1.0]

PARAMÈTRES: ~180,000
RÉSULTATS: AUC-ROC 0.91 | Recall 0.87 | F1-Score 0.85

1️⃣ load_processed_data() — FONCTION PRINCIPALE

   Objectif: Charger les données pré-traitées (X_train, y_train, etc.)

   Retourne 7 valeurs:
   ├─ X_train    (numpy array) → Shape: (?, 24, 13)   [train sequences]
   ├─ y_train    (numpy array) → Shape: (?,)          [train labels]
   ├─ X_val      (numpy array) → Shape: (?, 24, 13)   [validation sequences]
   ├─ y_val      (numpy array) → Shape: (?,)          [validation labels]
   ├─ X_test     (numpy array) → Shape: (?, 24, 13)   [test sequences]
   ├─ y_test     (numpy array) → Shape: (?,)          [test labels]
   └─ class_weight (dict)      → {0: 0.36, 1: 1.64}   [pour déséquilibre]

   Signification:
   ├─ X = données d'entrée (24 timesteps × 13 features)
   ├─ y = labels cibles (0=stable, 1=détérioration)
   ├─ 24 timesteps = 6 heures (15 min d'intervalle)
   └─ 13 features = (HR, SBP, DBP, SpO2, Temp, Resp, Lactate, WBC,
                      Creatinine, shock_index, HR_trend, SpO2_trend, HR_var)

   Utilisation:
   ┌───────────────────────────────────────────────────────────┐
   │ from src.data_loader import load_processed_data           │
   │ X_train, y_train, _, _, X_test, y_test, cw = \           │
   │     load_processed_data()                                 │
   │                                                           │
   │ print(X_train.shape)      # (45000, 24, 13)              │
   │ print(np.mean(y_train))   # 0.15 (15% positifs)          │
   │ print(cw)                 # {0: 0.36, 1: 1.64}           │
   └───────────────────────────────────────────────────────────┘

2️⃣ validate_sequence() — VALIDER UNE SÉQUENCE

   Objectif: Vérifier qu'une séquence est valide avant prédiction

   ├─ Pas de NaN
   └─ Pas de valeurs infinies

   Utilisation:

PREDICT.PY (12 LIGNES)
───────────────────────────────────────────────────────────────────────────────

def predict(X):
    # Load model
    model = final_model()

    # Make predictions
    y_score = model.predict(X).ravel()  # Scores bruts [0, 1]
    threshold = 0.5
    y_pred = (y_score >= threshold).astype(int)  # [0 ou 1]

    return y_pred, y_score

ENTREE: X (numpy array) shape (N, 24, 13)
   ├─ N = nombre patients/séquences
   ├─ 24 = timesteps (6 heures)
   └─ 13 = features (HR, SBP, SpO2, ...)

SORTIE: y_pred, y_score
   ├─ y_pred (array) : Classifications binaires [0, 1]
   │  ├─ 0 = PATIENT STABLE
   │  └─ 1 = DÉTÉRIORATION PROBABLE
   └─ y_score (array) : Probabilités brutes [0.0 à 1.0]

Utilisation:
┌───────────────────────────────────────────────────────────────────────┐
│ from src.predict import predict                                       │
│ import numpy as np                                                    │
│                                                                       │
│ # Prédiction unique                                                  │
│ y_pred, y_score = predict(X_test[0:1])                              │
│ print(f"Prédiction: {y_pred[0]}")      # 0 ou 1                    │
│ print(f"Score: {y_score[0]:.1%}")      # 78.5%                     │
│                                                                       │
│ # Batch predictions                                                  │
│ y_pred, y_score = predict(X_test[:100])                            │
│ print(f"Accuracy: {np.mean(y_pred == y_test[:100]):.2%}")          │
└───────────────────────────────────────────────────────────────────────┘

INTERPRÉTATION DES SCORES:
├─ Score < 0.35       → ✅ STABLE (pas d'alerte)
├─ 0.35 ≤ Score < 0.65 → ⚠️ SURVEILLANCE (risque modéré)
└─ Score ≥ 0.65       → 🚨 ALERTE CRITIQUE (risque élevé)
